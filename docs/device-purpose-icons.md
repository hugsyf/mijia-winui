## 显示规则

- 使用目录中的 `proxy_category_icon` PNG。
- 插座壁灯缺少该字段，使用其官方 `light_icon`。
- 按用途类型和适用型号匹配图片。
- 不将灯组编号用于插座。
- 未知用途回退到产品图片。
- 无线通道显示开关本体图片。
- 本机手动显示类别优先于云端外观。

图片来源和哈希位于 `Assets/Devices/purpose-index.json`。
记录中的 URL 已移除签名查询参数。
用途图片只改变显示。
真实属性和无线模式继续决定控制权限。

应用不调用 `/v2/device/set_sub_class` 修改云端用途。
