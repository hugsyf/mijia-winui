# MIOT 展示语言

适用应用版本：0.20.0。
文档修订日期：2026-11-08。

## 展示顺序

1. 使用适配包明确提供的标签。
2. 使用当前语言的设备官方元数据。
3. 使用宿主已确认的标准术语。
4. 缺少上述内容时，保留原文。

未知的自定义内部属性默认放入高级设置。
不要根据译文推测用途或控制权限。
不要自动翻译用户名称和设备字符串读数。

## 数据字段

| 字段 | 用途 |
| --- | --- |
| `name`、`service`、枚举 `description` | 原始描述 |
| `displayName`、`displayService`、`displayDescription` | 可选展示标签 |
| URN、SIID、PIID、类型、单位、权限和值 | 原始协议数据 |

翻译只改变显示。
属性匹配和控制请求继续使用原始协议数据。

## 官方多语言元数据

接口为 `https://miot-spec.org/instance/v2/multiLanguage`。
请求参数 `urn` 使用精确设备 URN。
简体中文读取 `data.zh_cn`。
英文读取 `data.en_us`，缺失时尝试 `data.en`。

服务键示例为 `service:002`。
属性键示例为 `service:002:property:003`。
`valuelist:000` 表示列表位置，不是枚举值。
实际值为 10 的首项仍使用位置 000。

数据按语言和 URN 缓存七天。
请求失败时保留旧缓存。
失败后延迟一小时再请求。
下载上限为 512 KiB。
请求使用固定 HTTPS 地址，不跟随重定向。
请求不包含账号、设备 ID 或读数。

## 适配包标签

`choice` 和 `select` 可以使用 `options`。
每项标签必须对应实际枚举值。
不得增加或重复枚举值。

`indicator` 使用 `states` 显式映射色调。
未知或缺失状态不能显示为成功。
中文标签不增加控制能力。
原始内容继续保留在导出资料中。

界面资源和适配包字典见[更新与界面语言](updates-and-localization.md)。
